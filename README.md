# סטודיו תבור — אתר הדגמה

**אתר דמו.** העסק, הכתובת, הטלפון, המייל, הרשתות והביקורות בדויים. התמונות מ-Unsplash (ראו [CREDITS.md](CREDITS.md)).
העיצוב והמבנה זהים לתבנית שממנה הועתק.

אתר סטטי בעמוד אחד. HTML + CSS + JS בלבד, בלי build, בלי ספריות.

```
index.html               העמוד
assets/css/style.css     עיצוב (טוקנים בראש הקובץ)
assets/js/main.js        גלילה, תפריט, לוח שנה
assets/availability.json תאריכים תפוסים
assets/img/              תמונות (hero-*, g-*, ig-*, about.jpg, og.jpg, logo-white.png)
```

## לעדכן תאריכים תפוסים
מוסיפים תאריך לרשימת `booked` ב-`assets/availability.json` בפורמט `YYYY-MM-DD`. שבתות מסומנות סגורות אוטומטית. אם הקובץ לא נטען, הלוח מוסתר ומופיעה הפניה לוואטסאפ.

## להחליף תמונות
- **הירו:** `hero-1 … hero-5` ברוחב 1920 + `hero-N-m.jpg` ברוחב 1000 למובייל. `hero-5` הוא הפריים האחרון.
- **גלריה:** `g-*` בקצה ארוך 1400, בלי כיתובים. גלילה אנכית מזיזה את הרצועה הצידה; הגובה מחושב ב-JS.
- **אינסטגרם:** `ig-01 … ig-12` ב-640.
